# Helping Hands

Public website for Helping Hands, a senior companion and home support business in Grand Bend, Ontario (also Port Franks, Thedford, Exeter and surrounding communities).

Built with Vue 3 + Vite. Fully responsive, mobile-first. Deployed automatically to GitHub Pages at https://ericlesl.github.io/helping-hands/ on every push to `main`.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Site

- Services, pricing ($30/hour, 2 hour minimum), how it works, scheduling, about, FAQ, request-a-visit form, and grocery list form.
- Both forms open a pre-filled email to helpinghands.miranda@gmail.com (mailto) - Miranda confirms every visit personally by phone. Nothing is booked automatically.
- Contact: (548) 888-9570 (call or text), helpinghands.miranda@gmail.com
- Non-medical support only.
